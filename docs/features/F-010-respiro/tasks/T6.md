## Goal

A última conta derivada que o app ainda faz sai do cliente. `CardSaldo` passa a consumir
`rotaPercorridaBps` e `saldoInicialDaRota`, campos tipados vindos de `GET /v1/dividas/resumo`, e o
comportamento visível não muda.

## Scope

- `src/api/types.ts` — `saldoInicialDaRota: number | null` e `rotaPercorridaBps: number | null` na
  interface `ResumoDividas`.
- `src/components/rota/CardSaldo.tsx` — as linhas 22-26 saem:

  ```ts
  const inicio = resumo.evolucaoSaldo[0]?.saldo;
  const temHistorico = inicio !== undefined && inicio > resumo.totalDevido;
  const percorrido = temHistorico
    ? Math.round(((inicio - resumo.totalDevido) / inicio) * 100)
    : undefined;
  ```

  O componente passa a ler os dois campos. O comportamento de **esconder a barra sem histórico** é
  preservado, agora pelo `null` que vem do servidor em vez de pela comparação local. O comentário
  do topo do arquivo (linhas 15-19) precisa passar a descrever a origem nova.
- `src/components/rota/CardSaldo.test.tsx` (novo) — o primeiro teste dedicado deste componente.

## Out of Scope

- **Qualquer mudança de layout, cor ou copy** do card além da origem do número. A barra continua
  com trilho em `colors.neutralSurface` e preenchimento em `colors.primary`.
- **Backend.** T3 já entregou os campos; não toque em `backend/`.
- **Respiro e marcos.** Você vai editar `src/api/types.ts`, que T5 também edita — mexa só em
  `ResumoDividas`, não na interface `Caixa`.
- Não remover `evolucaoSaldo` do tipo nem do consumo: o gráfico de evolução do painel usa a série.

## Acceptance Criteria

- **T6-AC1** — nenhum componente do app calcula a porcentagem da rota.
  Como conferir: `grep -rn "evolucaoSaldo\[0\]" src app` não devolve nada.
- **T6-AC2** — com `rotaPercorridaBps` nulo, o card mostra só o número e a contagem de dívidas,
  exatamente como hoje.
  Como conferir: teste com o campo nulo.
- **T6-AC3** — a barra continua enchendo com o que já foi percorrido, nunca com o que falta.
  Como conferir: teste que passa `rotaPercorridaBps: 2740` e prova largura de 27,4%, não 72,6%.
- **T6-AC4** — o teste novo cobre os dois casos, com e sem histórico.
- **T6-AC5** — os gates passam: `npm run typecheck`, `npm run lint`, `npm test`,
  `npm run bundle:check`.

## Known Risks

- **Trocar a origem e mudar o comportamento sem perceber.** Hoje a barra some quando não há ponto
  anterior maior que o saldo; o `null` do servidor precisa produzir exatamente o mesmo efeito.
- **Converter basis point como se fosse porcentagem.** `2740` é 27,4%, não 2740%.
- Esta é a menor tarefa do milestone. Se ela crescer, é sinal de que algo de T3 não chegou.
